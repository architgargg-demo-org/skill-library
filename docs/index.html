GitHub Copilot app / Skill Library

One plugin. Every library skill.

architgargg-test-plugin packages the repository's entire skills/ directory. No separate skill downloads are needed.

These links open the installed desktop app; they do not install the app itself or silently install a plugin. Review the confirmation and submit the pre-filled form in the app. Add the marketplace before installing the plugin. Only install sources you trust.

1. Install and sign in to the app

Download the GitHub Copilot app, install it, open it, and sign in with a GitHub account that can read this repository. Update an existing app installation first. This repository is internal; access to this page does not grant access to its plugin source.

2. Add the marketplace

Add marketplace in Copilot

If your browser asks, allow this link to open GitHub Copilot. Review the source, accept the app's confirmation, then submit the add-marketplace form. The registered marketplace is named architgargg-skill-library.

3. Install the plugin

Install plugin in Copilot

Review the confirmation, then click Install in the pre-filled form. You can also find architgargg-test-plugin in the app's plugin-management screen and install it there. Depending on your app version, this screen is under Settings > Plugins or Customize.

4. Check the installation

Start a new Copilot session and ask:

Run the skill library smoke test.

Expected response:

Skill Library smoke test passed: architgargg-test-plugin loaded this skill.

Also verify that skill-library-smoke-test appears in the app's available skills. A matching response alone is not proof that a skill loaded. The sample skill has no external services, credentials, hooks, or MCP servers. Future skills can have their own dependencies; review their instructions.

Terminal fallback

With GitHub Copilot CLI installed and authenticated, run:

copilot plugin marketplace add architgargg-demo-org/skill-library
copilot plugin install architgargg-test-plugin@architgargg-skill-library
copilot plugin list
copilot skill list

In an interactive CLI session, /skills list also lists the skills.

If a link does not work

  • No app opens: install or update the desktop app, or use the terminal fallback. GitHub Pages only serves this page; the operating system handles ghapp://.
  • Marketplace not found: finish step 2 first, and confirm that the plugin manifests have been merged into the repository's default branch.
  • Repository access denied: check your GitHub sign-in and organization authorization, including SSO if required. Pages and repository authentication are separate.
  • Missing new skills: refresh the marketplace, update the installed plugin in the app, and start a new session. CLI equivalents: copilot plugin marketplace update architgargg-skill-library and copilot plugin update architgargg-test-plugin@architgargg-skill-library.

How this is built

The marketplace catalog is .github/plugin/marketplace.json. Its plugin source is the repository root, where plugin.json includes ./skills/. Maintainer-reviewed skills added there ship together when users update the plugin. No duplicate skill directory, installation script, token in a URL, or automatic redirect is needed.

See the repository's publishing instructions for Pages setup and the exact link format.
